# 🍔 Foodora India — Food Delivery Performance Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze food delivery performance, revenue, orders, payment methods, delivery methods, and operational factors.

The project uses **PostgreSQL, SQL and Power BI** to transform raw order data into meaningful business insights.

## 🎯 Key KPIs

- Total Orders
- Total Revenue
- Average Order Value
- Average Delivery Time

## 🔍 Analysis Covered

- Order Status Distribution
- Payment Method-wise Orders
- Revenue by Payment Method
- Revenue by Delivery Method
- Monthly Revenue Trend
- Monthly Orders Trend
- Traffic Level Analysis
- Weather vs Average Delivery Time
- Average Order Value by Order Status

## 🛠️ Tools & Technologies

- **PostgreSQL** — Database
- **SQL** — Data Analysis
- **Power BI** — Dashboard & Data Visualization

## 💡 Key Skills Demonstrated

- Data Analysis
- SQL Querying
- KPI Development
- Data Visualization
- Dashboard Design
